# A1 Design System Handoff — Tokens + Primitives

## What Changed
- **`src/index.css`**: Replaced legacy color tokens with new spec-compliant design tokens (§1)
  - Added all surface colors (`--bg-app`, `--bg-panel`, `--bg-raised`, `--bg-hover`, `--bg-active`)
  - Added text hierarchy (`--text-1`, `--text-2`, `--text-3`, `--text-disabled`)
  - Added accent + semantic colors (`--accent`, `--success`, `--warn`, `--danger`)
  - Added spacing scale (4px–48px, 8pt grid)
  - Added control heights (`--h-sm: 28px`, `--h-md: 36px`, `--h-lg: 44px`, `--row-height: 56px`)
  - Added radii (`--r-sm: 6px`, `--r-md: 8px`, `--r-lg: 12px`)
  - Added motion tokens (`--t-fast: 140ms`, `--t-med: 200ms`, `--t-slow: 280ms`)
  - Added focus ring variables (`--focus-ring`, `--focus-offset`)
  - Added legacy aliases for gradual migration (marked DEPRECATED)
  - Removed background gradient pattern from body
  - Removed `.slab` font class (Zilla Slab deleted per §1.4)
  - Added typography utility classes (`.text-overline`, `.text-caption`, `.text-body`, etc.)
  - Added global `:focus-visible` styles per §1.9
  - Updated scrollbars to use `--border-strong` thumb per §1.10
  - Added `scrollbar-gutter: stable` utility class

- **`tailwind.config.js`**: Mirrored CSS tokens into Tailwind theme
  - All colors now reference CSS custom properties via `var()`
  - Removed hardcoded hex values
  - Removed `slab` font family (no longer available)
  - Added fontSize scale matching spec §1.4
  - Added spacing, height, borderRadius, transitionDuration utilities
  - Added custom width utilities (`sidebar: 240px`, `rail: 360px`)

- **`src/primitives/`** (NEW DIRECTORY): Created all primitive components per §2
  - `Button.tsx`: variant (primary|secondary|ghost|danger), size (sm|md)
  - `IconButton.tsx`: with mandatory tooltip + aria-label (fixes C8)
  - `Switch.tsx`: accessible toggle with keyboard support (fixes C1)
  - `Badge.tsx`: tone (accent|success|warn|danger|neutral), variant (subtle|outline|solid)
  - `Input.tsx`: h36, label/helperText support, focus ring
  - `Select.tsx`: CUSTOM listbox replacing native `<select>` (fixes C2)
  - `Checkbox.tsx`: custom square with accent check
  - `Chip.tsx`: toggleable filter tags
  - `Kbd.tsx`: for Ctrl+K hints
  - `EmptyState.tsx`: compact empty state (fixes C5)
  - `Tooltip.tsx`: hover/focus tooltip with delay
  - `index.ts`: barrel exports

## Tokens/Components Consumed
All primitives consume the CSS custom properties defined in `src/index.css`:
- Surface colors: `--bg-*`, `--border-*`
- Text colors: `--text-*`
- Accent/semantic: `--accent-*`, `--success-*`, `--warn-*`, `--danger-*`
- Sizing: `--h-*`, `--r-*`, `--space-*`
- Motion: `--t-*`
- Focus: `--focus-ring`

None. All primitives implemented exactly per §2 specification.
